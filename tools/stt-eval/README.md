# stt-eval — замер распознавания на своих диктовках

Код без данных. Звук и эталон лежат только на маке владельца и в git не попадают.

## Набор

Переменная `SUSU_TESTSET` — папка набора (по умолчанию `~/Projects/susu/research-private/stt`):

```
clips/c01.wav … c50.wav     диктовки, 16 кГц моно
clips/clips.json            [{"id": "c01", "lang": "ru", "wispr_asr": …, "wispr_formatted": …, "e2eLatency": …}, …]
refs.json                   {"c01": {"text": "эталон", "keys": ["InboxKit"], "doubtful": []}, …}
hint.txt                    подсказка-словарь: «вступление: термин, термин, …»
runs/<имя>.json             прогоны
```

Формат прогона: `{"c01": {"text": "распознанный текст", "sec": 0.54}, …}`. `sec` — секунды от начала отправки до готового текста.

## Команды

```bash
python3 -I tools/stt-eval/evaluate.py "$SUSU_TESTSET"        # таблица по всем прогонам: ошибка, русский, названия, медиана
python3 -I tools/stt-eval/check.py "$SUSU_TESTSET/runs/X.json" --names 0.90 --wer-ru 0.12 --sec 0.6
python3 -I tools/stt-eval/editor_table.py "$SUSU_TESTSET"/runs/susu-editor-*.json   # таблица прогонов редактора (T2.5): Р1, Р4, Р5, прибавка в мс
python3 -I tools/stt-eval/test_check.py                      # самопроверка check.py (входит в make test)
```

`check.py` выходит с кодом 1, если прогон не прошёл. Пороги задаются флагами, без флага не проверяются. Всегда проверяются:
- **Р3** — английские клипы вернулись по-английски (больше половины букв латиница);
- **Р4** — слово словаря стоит там, где его не говорили. Если в эталоне то же слово кириллицей («Телеграме» → Telegram), это не ошибка.

**Р5** (лишние латинские слова, которых нет ни в эталоне, ни в словаре) печатается всегда, а порог включается флагом `--r5-max 0`. Это проверка для редактора (T2.5). Сырое распознавание пишет латиницей и ошибки вроде «CloudCode», поэтому на нём Р5 не ноль.

Названия сравниваются с точностью до процента, как в отчёте этапа 2: 78,7% проходит порог 79%.

## Языки (`multilang/`)

Синтетический набор на 15 языках: фраза с английскими названиями и фраза со смесью «язык + английское предложение». Голоса встроены в macOS, звук генерируется командой и в git не кладётся.

```bash
tools/stt-eval/multilang/gen.sh DIR                          # 30 WAV голосами macOS (тексты и голоса — texts.json)
python3 -I tools/stt-eval/multilang/run.py DIR               # Groq turbo без подсказки и с ней → DIR/results.json (~4 мин)
python3 -I tools/stt-eval/multilang/score.py DIR --gate whisper-large-v3-turbo+hint
```

Планка для провайдера по умолчанию (`--gate`): медиана ошибки ≤ 10%, язык угадан 15 из 15, названия ≥ 80% с подсказкой. Для японского и китайского ошибка считается по символам.
